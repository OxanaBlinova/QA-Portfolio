# BUG_LOGIN_003 — Login Button Remains Disabled with Valid Input

**Environment:**
- OS: macOS
- Browser: Chrome
- Environment: Test

**Preconditions:**
- User is on Login page

**Steps to Reproduce:**
1. Open Login page
2. Enter a valid email format
3. Enter a valid password
4. Observe the Login button state

**Expected Result:**
- Login button becomes enabled

**Actual Result:**
- Login button remains disabled

**Severity:** Medium  
**Priority:** Medium

**Notes:**
- Issue blocks basic user flow and negatively impacts usability.
