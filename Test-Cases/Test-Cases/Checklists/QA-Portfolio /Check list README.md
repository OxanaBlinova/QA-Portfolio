# Checklists – Login Module

This folder contains structured checklists used for quick validation of the Login functionality.  
Checklists offer a lightweight alternative to detailed test cases and are often used during smoke testing, regression testing, or fast QA reviews.

---

## ✔️ Included Checklists

### • Login_Checklist.md
Covers:
- UI elements visibility (inputs, labels, buttons)
- Email/Password field validation
- Button state behavior (disabled/enabled)
- Error message behavior
- Security checks (password masking)
- Navigation and redirects
- Basic negative scenario checks

---

## 🎯 Purpose of This Folder

- Provide a quick way to validate key login functions.
- Reduce testing time for repeated flows.
- Support smoke/regression testing.

---

## 📂 Structure

- Each checklist is maintained as a `.md` file.
